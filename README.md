# 嘿樂肥｜第二版圖解使用說明書

[開啟線上說明書](https://k0982854972.github.io/heylefei-manual/)

2026-10-02：**8 個主要步驟＋20 張實際系統畫面**。購物車 → 結帳與銀行轉帳 → 商家人工核款 → 出貨；每步用短句說明。

- 圖片可點開放大，Esc 關閉；圖片內嵌，下載 `index.html` 可離線閱讀。
- 可列印／儲存 PDF；補充操作請先展開再列印。
- 補充首次填資料、常用地址、商品／配送設定、人工建單、報表及取消退款。
- 畫面取自隔離假資料的實際操作；付款、退款與配送皆模擬，未發送 LINE 訊息。
- 真實 LINE 登入、通知及跨裝置驗收另外進行；本頁只提供文件，不包含系統登入入口、憑證或既有客戶資料，也不代表正式系統上線。

維護時替換 `index.html` 並同步本頁版本說明，再推送 `main`；GitHub Pages 自動發布。
