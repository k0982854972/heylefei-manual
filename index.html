第一版使用說明書

從商家接單、備貨與收款，到客人選購、付款回報與查單，依照日常工作一步步操作。

商家管理客人操作備齊請款・收款後出貨
我是店家／管理人員 →認識後台，處理接單、款項與出貨。我要了解客人的操作 →查看客人如何下單、回報付款與找回訂單。
01

先了解訂單流程

本說明書提供委託店家與使用人員閱讀，適用於目前第一版的新訂單流程。店家使用商家後台管理訂單；客人透過 LINE 入口選購與查看自己的訂單。

先備齊、再請款；確認足額收款後，才出貨。

客人送出訂單不代表商家已接單，選擇付款方式或回報付款也不代表店家已收到錢。

全部是現貨的訂單

  1. 客人送單
  2. 核對現貨
    接單並請款
  3. 客人付款
    回報付款
  4. 商家確認
    足額收款
  5. 登記出貨

需要製作，或現貨與製作商品一起下單

  1. 客人送單
  2. 商家接單
    製作／備貨
  3. 整筆備齊
    再請款
  4. 客人付款
    商家核款
  5. 登記出貨

兩種訂單請款後，都可使用當時開放的銀行轉帳或私人 LINE Pay。混合單採整張備齊、一次足額付款、一次整單出貨。

看到的狀態代表的意思接下來由誰處理
待商家確認客人已送出，商家尚未接單。商家核對內容並決定是否接單。
製作／備貨中已接單，尚未整筆備齊並請款。商家完成製作及備貨。
備貨完成・待付款已請款，等待客人付款及商家核款。客人付款回報，商家核對。
待確認款項已回報付款，商家尚未確認入帳。商家核對實際款項。
已收款／待出貨商家已確認足額收款。商家安排實際出貨。
已出貨商家已登記寄出。可查看出貨紀錄；不代表物流已送達。
已取消此筆訂單不再繼續處理，歷史仍保留。需要重新購買時另建新訂單。

頁面可能分別顯示訂單進度與收款狀態，請一起查看。較早建立的歷史訂單可能沿用原流程，不套用本節的新單順序。

02

登入與開始前設定

店家／員工

  1. 使用管理者提供的員工入口，依畫面透過 LINE 登入。
  2. 首次使用若顯示待核准，請由管理員確認人員資格。
  3. 登入後確認自己的身分；看到的功能依權限而定。

員工帳號須完成核准及必要的 LINE 綁定。客戶登入不會自動取得員工權限。

購買商品的客人

  1. 從店家提供的客戶選購入口進入。
  2. 依畫面完成 LINE 登入／授權。
  3. 首次使用依提示填寫資料，再選品與下單。

請使用原本下單的 LINE 帳號查單；是否需再次授權，依當下登入狀態而定。

店家開始接單前，先確認這些項目

  • 商品名稱、圖片、規格、單位與價格正確。
  • 商品的公開展示、開放接單及供貨方式符合實際情況。
  • 已設定固定運費；有銀行轉帳需求時，已填妥匯款資訊。
  • 人員權限及提醒收件人已確認。
  • 先用一筆標記清楚的測試單熟悉流程，試用時不進行真實付款或寄送。

本版目前供試用與確認，正式營運入口由交付人員另行提供。試用期間入口與通知對象可能受限；無法進入時請聯絡管理者。

03

每日工作與功能導覽

入口：管理首頁

登入後先查看每日工作總覽，點選待辦卡片前往對應清單。必要時按「重新整理」取得最新狀態。

先處理接單與備貨

查看「待商家確認」和「製作／備貨中」，核對能否供應及哪些商品需要準備。

再核對款項與出貨

處理「待提供私人 LINE Pay QR Code」及「待確認款項」，查看今天與逾期待出貨。

後台功能什麼時候使用
訂單管理搜尋訂單、接單、查看明細，或人工代客建立訂單。
待出貨切換製作／備貨與各日期待出貨清單、查看商品彙整、列印備貨清單。
收款管理查看已請款未收、待確認、已收款及待提供 QR Code 訂單。
客戶資料維護聯絡資料，查詢客戶歷史訂單。
商品資料管理商品內容、圖片、價格、接單及供貨方式。
下單設定設定固定運費與銀行匯款資訊。
操作紀錄查閱業務操作的時間、人員與內容。
通知紀錄／每日提醒查閱訊息處理狀態，管理每日提醒收件人。

首頁「已請款未收金額」包含客人已回報、但商家尚未確認的款項；尚未請款與取消訂單不計入。管理員限定功能可能不會顯示在一般員工畫面。

04

商品、客戶與下單設定

新增或修改商品

入口：商品資料 → 新增商品／修改資料（管理員）

  1. 填寫品名、商品編號、網址代稱、規格、單位、價格與說明，依需要上傳圖片。
  2. 設定是否公開展示及開放接單，兩者用途不同。
  3. 選擇「現貨供應」或「接單後製作」，可補充準備時間說明。
  4. 儲存後確認清單與客戶頁面顯示。
供貨方式不是庫存數量。

「現貨供應」仍需要店家確認實際數量；本版不會自動保留或扣除庫存。修改商品也不會直接改寫既有訂單的商品內容與價格。

不同商品／規格使用不同且不重複的商品編號。商品網址代稱一旦公開便不可再修改；欄位格式依畫面提示填寫。

維護客戶資料

入口：客戶資料 → 新增客戶／修改資料

維護姓名、電話、地址及選填的 LINE 聯絡備註。可以搜尋姓名或電話，透過「查看歷史訂單」查閱該客戶的訂單。停用客戶會保留歷史紀錄。

LINE 聯絡備註只供人工辨識，不會自動綁定 LINE 帳號；姓名或電話相同，也不會自動合併成同一位客戶。

設定運費及銀行資訊

入口：下單設定 → 儲存下單設定（管理員）

  • 固定運費：每張訂單使用設定金額，0 元代表免運。尚未設定時，客戶無法正常完成選品下單。
  • 銀行轉帳資訊：填寫銀行、分行、戶名、帳號與必要匯款說明。留白時，銀行轉帳選項停用。

匯款資訊於每次請款時保留當時版本。之後修改設定不會更新已請款訂單；需重開請款時，請依修改與更正流程處理。

05

接單、備貨與請款

入口：訂單管理 → 查看訂單

收到客人新單

  1. 找到待商家確認的訂單，核對商品、規格、數量、金額、收件資料及預計出貨日期。
  2. 全現貨且數量充足：按「確認接單並請款」。
  3. 需要製作、混合單或仍須準備：按「確認接單」，先進入製作／備貨。
  4. 無法承接時，開啟「無法接單」，填寫原因並按「拒絕接單」。請另行聯絡客人，這個動作不會自動發送拒絕接單的 LINE 訊息。

整筆備齊後再請款

入口：待出貨 → 製作／備貨中 → 核對備貨並請款

  1. 查看備貨商品與數量，確認整張訂單都已備齊。
  2. 在訂單內填寫暫定出貨日期。
  3. 按「備貨完成並請款」，確認提示內容。
  4. 客人可在原訂單選擇付款方式；符合通知設定時，會發出備貨完成請款訊息。

預計出貨日是安排日期，不代表已寄出。收到款項後仍可確認或調整出貨安排；請勿在尚未寄出時登記已出貨。

人工代客建單

入口：訂單管理 → 新增訂單

  1. 先建立或選取客戶，核對本次收件資料。
  2. 加入商品、數量，核對金額、運費、日期與備註。
  3. 儲存訂單，再核對備貨、請款與收款。

人工單同樣採備齊請款、足額收款後出貨。未連結客戶 LINE 身分的人工單，請商家另行聯絡，不要假定客人一定會收到系統通知。

06

付款需求與確認收款

入口：收款管理

「全部未收款」包含已回報、尚待核款的訂單；「待確認款項」協助集中核對回報。「待提供 QR Code」是私人 LINE Pay 的人工協助待辦。

銀行轉帳

  1. 客人在已請款訂單選銀行轉帳，查看匯款資訊並付款。
  2. 客人回報付款，可填匯款帳號末五碼。
  3. 商家核對銀行實際入帳金額、時間及相關資料。
  4. 核對無誤後，在後台確認足額收款。

私人 LINE Pay

  1. 客人選擇私人 LINE Pay，系統建立 QR Code 需求。
  2. 客人在官方聊天室提供訂單編號。
  3. 商家核對編號、客人與金額，人工傳送 QR Code，並按「已人工提供 QR Code」。
  4. 客人付款回報後，商家核對實際入帳，再確認收款。
目前兩種方式都由商家人工核款。

系統尚未自動查詢銀行或私人 LINE Pay 的款項，也不會自動產生、傳送私人收款 QR Code。「已人工提供 QR Code」只記錄提供動作，不代表已收款。

在後台確認足額收款

  1. 開啟要核對的訂單，先確認訂單編號與應付金額。
  2. 依實際款項選擇付款方式，填寫實收金額與實際付款時間；末五碼、交易參考資料可依需要補充。
  3. 實際付款時間以台灣時間填寫，應介於請款當分鐘與現在之間。
  4. 按「核對完成，確認足額收款」，再次確認提示。

完成後，訂單顯示已收款並可安排出貨；符合設定時，客人會收到已收款通知。僅使用「僅回報付款，待核對」不會確認收款。

本版接受單張訂單一次足額收款。零元單、部分款、超額及合併款請交管理員人工核對，不要為了通過畫面而填寫不符實際的收款金額。

07

出貨、列印與紀錄

安排並登記出貨

入口：待出貨 → 核對並登記出貨

  1. 查看今天、明天、未來或逾期的待出貨訂單。新流程訂單須備齊且已收款才會進入可出貨清單。
  2. 如需調整日期，於訂單內填「確認預計出貨日期」，按「儲存出貨安排」。
  3. 再次核對收件姓名、電話、地址、商品、數量與備註。
  4. 實際寄出後填寫實際出貨時間、配送方式及選填物流單號，按「確認已出貨」。

出貨時間不可晚於現在；新流程也不得早於有效收款確認當分鐘。登記後訂單移出待出貨清單，客戶頁面更新為已出貨，並依設定發送通知。

補登物流單號或配送資訊

在訂單的出貨紀錄開啟「補登配送資訊／修改備註」，修改後按「儲存配送資訊」。這裡不會變更商品、金額或原出貨時間，也不會向物流公司建立寄件單。

列印與儲存 PDF

文件適合用途操作方式
訂單明細查看單張訂單的商品、金額及狀態。在訂單開啟列印頁，按「列印／儲存 PDF」，於瀏覽器選印表機或儲存 PDF。
備貨核對清單彙整符合條件的商品與規格數量，方便備貨。在待出貨頁先設定分類／搜尋條件，再按「列印備貨清單」。

列印內容以產生當下為準，訂單修改後應重新列印。紙本勾選不會更新訂單或登記出貨；訂單明細不是發票或收款證明。

查閱歷程

訂單內可查看收款、出貨及操作紀錄；管理員也可從「操作紀錄」查閱相關處理。更正前先看紀錄，避免把同一件事重複處理。

08

修改、取消與更正

先確認訂單目前是否已請款、客人是否已付款、貨物是否真的寄出，再選擇處理方式。若按鈕沒有顯示，可能是目前狀態或登入權限不允許。

遇到的情況處理方式
尚未請款，需修改訂單商家在可編輯的訂單按「修改訂單」，核對後儲存；若仍待審，先完成接單處理。
已請款，客人尚未回報或付款先聯絡確認未付款，開啟「撤回請款並重新備貨」，填原因並按「確認撤回請款」；修改後重新核對備貨並請款。
已回報付款或已有有效收款不能直接撤回請款。請先人工核對；已收款單不能直接改價或取消。
需要取消未收款訂單由管理員核對是否允許取消，填取消原因並確認；請另行聯絡客人。取消後保留紀錄，不能直接復原。
誤登收款管理員確認後使用「更正：作廢錯誤收款」，填原因再更正。這不會退款；需要退款請另行處理。
誤登出貨管理員確認貨物尚未真正寄出，再使用「更正：撤銷出貨登記」，填原因。新流程保留原收款；這不是退貨、退款或物流攔件。

撤回請款後，客人原付款表單將失效。請客人重新開啟訂單，等待新的請款資訊；避免沿用舊資訊或重複付款。

部分已出貨歷史單保留舊有更正规則。若實際款項、配送與系統紀錄不一致，先交管理員核對，不要以多次更正操作代替真實退款或退貨處理。

09

客人下單與查詢

以下是客人從 LINE 入口購買時的操作，可用於向客人說明。

① 選擇商品並確認收件資料

  1. 進入店家提供的客戶入口，依畫面完成 LINE 登入。
  2. 開啟「選品下單」，填寫想購買的數量。數量 0 表示不選購。
  3. 確認收件姓名、電話與完整地址，可填寫配送備註。
  4. 按「下一步：確認訂單」，核對商品、數量、運費、總額與預計出貨日期。
  5. 確認後按「確認送出，等待商家確認」，等待結果。

修改本次收件資料不會更改先前訂單。送出期間按鈕可能暫時停用，請等待，不必連續點擊。

② 從「我的訂單」查看進度

開啟「我的訂單」找到該筆訂單，再按「查看訂單」。商家處理後，可按「重新整理狀態」查看新進度。含需製作商品時，需等商家整筆備齊並請款才會出現付款方式。

③ 選擇付款方式並回報

  1. 於已請款的訂單選擇銀行轉帳或私人 LINE Pay，按「確認付款方式」。
  2. 銀行轉帳：依該筆訂單的匯款資訊完成轉帳。私人 LINE Pay：在官方聊天室提供訂單編號，等商家核對並提供 QR Code。
  3. 完成付款後，回訂單按「我已付款，請商家核對」；銀行末五碼可選填。
  4. 等待商家核款，商家確認後才會顯示已收款。
已付款但還顯示未收款？

請先查看是否已回報，聯絡商家核對並提供訂單編號。不要因狀態尚未更新就再付一次。付款方式選定後若需更改，也請聯絡商家。

④ 查看出貨通知

商家登記出貨後，訂單頁會顯示已出貨，並依通知設定透過官方 LINE 帳號發送訊息。可從通知中的連結回到訂單查看最新狀態。

需要改單、取消或調整收件資料時，請聯絡商家；客人目前不能自行在訂單內修改金額或取消訂單。

10

LINE 通知與每日提醒

通知對象訊息用途
該筆訂單的客人接單備貨、接單請款或備貨完成請款、確認收款、出貨，以及適用的請款／收款更正通知。
符合提醒設定的店家人員私人 LINE Pay QR Code 需求與每日待出貨摘要。

通知從官方 LINE 帳號發出。一般客人不會因為下單就收到商家內部提醒；同一 LINE 若同時具有客戶及員工身分，則可能收到兩種用途的訊息。

開啟員工每日提醒

  1. 確認人員已核准啟用、已綁定 LINE，並已加入店家官方帳號好友。
  2. 管理員開啟「每日提醒」，於收件人設定按「開啟提醒」。
  3. 系統通知功能也須啟用；若頁面顯示每日推送尚未啟用，請聯絡管理者處理。

每日以台灣時間 09:00 起處理今天、明天及逾期待出貨摘要；三項皆為零時不發送。這是工作提醒，不是自動催款。

LINE 接受訊息不等於收件人已讀。通知可能稍後送達，請以訂單最新紀錄為準；通知失敗不會撤銷已完成的收款或出貨。試用期間只對指定身分發送。

常見問題與本版範圍

為什麼銀行轉帳不能選？

該次請款未包含匯款資訊。客人請聯絡商家；商家補存設定後，仍須在確認客人未付款且符合撤回條件時，撤回並重新請款，才會使用新的匯款資訊。

為什麼不能出貨，或找不到待出貨訂單？

新流程需已接單、整筆備齊並請款、確認足額收款。僅回報付款還不能出貨。先查訂單進度，再檢查日期與搜尋條件；製作中的訂單請切換「製作／備貨中」。

送出後沒有結果，或網路中斷怎麼辦？

先恢復連線，再從「我的訂單」或後台搜尋確認是否已成功儲存。不確定結果時不要立刻重建同一筆訂單；若出現資料已失效，重新載入並核對最新內容再操作。

登入後找不到原本的訂單？

確認使用當時下單的 LINE 帳號與客戶入口，再重新整理。仍找不到時，提供訂單編號請商家協助核對。

為什麼我看不到商品設定、取消或更正按鈕？

不同人員權限及訂單狀態會影響可用操作。請先確認目前登入身分；商品設定、取消與部分更正由管理員處理。

為什麼沒有收到 LINE 通知？

先確認訂單狀態是否已更新，再檢查是否使用正確帳號、已加入官方帳號好友及符合收件設定。商家可查看通知紀錄；試用期間另有指定名單限制。不要為了重發訊息而重做收款或出貨。

網站突然無法開啟？

先確認網路；目前試用服務可能受測試主機或入口調整影響。請向提供入口的窗口反映發生時間與錯誤畫面，等待確認後再操作。

目前提供接單、備貨、人工核款、出貨登記、客戶查單及相關通知。以下尚未包含：自動庫存／效期管理、分批出貨、訂金或分期、線上金流自動入帳、物流自動下單、電子發票、自動退款，以及郵件自動對帳。
